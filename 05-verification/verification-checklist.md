# Verification Checklist & Application

## Personal Verification Checklist
1. Identify the core data points (dates, names, metrics).
2. Set accurate verification criteria against source documents or CRM.
3. Test AI output against trusted organizational records.
4. Confirm constraints and flag missing information as [Not Specified][cite: 1].
5. Document final decision and human approval.

## Applied Example
Applied the checklist to the Information Workflow action items: verified that sentiments align with the raw text, ensured no real customer names were generated by AI, and marked missing details like tool budgets as [Not Specified][cite: 1].
