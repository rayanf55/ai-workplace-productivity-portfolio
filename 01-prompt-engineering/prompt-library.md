# Prompt Library

| Prompt Name | Workplace Task (When to use it) | Framework | Prompt | Expected Output |
|---|---|---|---|---|
| Feedback Sentiment Analyzer | I use this prompt when I need to quickly categorize weekly raw feedback into positive, neutral, and negative sentiments. | C.A.R.E. | **Context:** We received 50 mixed reviews on our new app update. **Action:** Categorize these reviews. **Role:** Customer Experience Analyst. **Expected Output:** A bulleted summary with actionable pain points. | Structured list of pain points and sentiment breakdown. |
| Apology Email Generator | I use this prompt when a customer experiences a service failure and requires a fast, empathetic response. | R.C.T.O. | **Role:** Senior CX Analyst. **Task:** Draft an apology email to a customer for a delayed refund. **Context:** Refund delayed by 5 days, offering a 20% discount. **Output:** A polite email template. | **Example Output:** "Dear Customer, I sincerely apologize for the 5-day delay in processing your refund. Please accept this 20% discount code: CX20." |
| Urgency Classifier | I use this prompt when the support inbox is flooded and we need to immediately identify high-risk financial tickets. | C.A.R.E. | **Context:** Inbox is flooded with new tickets. **Action:** Classify the ticket urgency (High/Med/Low). **Role:** Support Triage Analyst. **Expected Output:** Single line stating priority and reason. | **Example Output:** "High — customer reports a payment processing failure requiring immediate financial escalation." |
| FAQ Drafter | I use this prompt when a new recurring issue appears and we need to update the customer self-serve knowledge base. | R.C.T.O. | **Role:** CX Specialist. **Task:** Write a short FAQ answer. **Context:** Customers ask how to reset passwords. **Output:** 3-step instructional bullet list. | 3-step instructional text for the FAQ page. |
| CX Report Summarizer | I use this prompt at the end of the week to extract the most critical insights for the management team. | C.A.R.E. | **Context:** End of week CX metrics are ready. **Action:** Summarize the top 3 complaints. **Role:** Lead CX Analyst. **Expected Output:** Executive summary paragraph. | Executive summary highlighting top 3 issues. |
